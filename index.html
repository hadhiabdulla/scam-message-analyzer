Scam Message Analyzer.

Is this message a scam?

Paste a suspicious SMS, WhatsApp or email text. You get a risk level, the exact warning signs highlighted in your message, and plain-English reasons.

Instant check runs fully in your browser - nothing is sent anywhere. Live mode sends only the message text to a small relay that asks IBM watsonx.ai.

How it works

1. The risk score comes from our own rules, not from IBM

A small set of plain rules (rules.js in the repo) looks for warning signs: urgency, requests for OTP/PIN/card details, money asks, prizes, threats, shortened or IP links, look-alike link names, odd domain endings, gift cards, too-good earnings, and shouting in capitals. Each matched rule adds points and shows you the exact text it matched.

2. Live check with the trained IBM spam classifier

The Analyze live button sends only the message text to a small relay (a Cloudflare Worker). The relay keeps the account key secret, asks IBM watsonx.ai to score the text with the model trained for this project (TF-IDF + SVM ensemble on the UCI SMS Spam Collection), and returns spam or ham with the model's internal scores. To stay inside IBM's free quota, the scoring deployment is created on demand and automatically deleted after about 20-25 minutes - so the first live call after a quiet period can take a few minutes while it wakes up. Live calls are rate-limited to protect the quota.

3. IBM Watson NLP emotion results are separate context, run by you in a notebook

IBM's Watson NLP emotion model describes the feelings in a text. It does not decide whether a message is a scam (a prize scam reads as "joy"). Putting the account key in a public page would leak it, so the site keeps real Watson emotion outputs that were run in a notebook and clearly labels them as saved results.

To analyse a new message with Watson: on the result card press Copy notebook cell, run it in your watsonx.ai Studio notebook (runtime "NLP + DO Runtime ... XS", about 6 capacity units per hour from the free 10 per month - stop the runtime when done), then paste the printed JSON back into Add IBM Watson result.

4. Honest limits

  • Rule-based checks miss new tricks and sometimes flag genuine messages (a real OTP notice mentions "OTP").
  • A low score says "few warning signs - safety NOT established". It never means proven safe.
  • Small hand-written tests (36 messages) gave a rough picture only: they do not measure real-world accuracy.
  • The live model was trained on 5,574 English SMS messages from 2011. Its 98.55% figure is accuracy on a held-out split of that dataset, not on today's scam messages; modern scams, other languages and chat-app tricks can be missed. Its percentage is the SVM's internal score, not a calibrated probability.
  • When unsure: do not click links or share codes. Contact the company through its official app or number.
This tool is a helper, not a judge. The final call is yours.
